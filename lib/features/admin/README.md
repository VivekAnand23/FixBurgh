# admin

In-app admin tools: the society admin's Manage area (approve members,
promote committee members, post notices, upload documents) in Phase 1.

Platform admin work (society claims, provider approval, payments,
sponsorships) happens in the web console at `hosting/public/admin`, open to
accounts with the `platformAdmin` custom claim
(`functions/scripts/set-platform-admin.js`). Empty for now.
